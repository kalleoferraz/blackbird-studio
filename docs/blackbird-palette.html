Blackbird Palette

Twelve colors taken from a blackbird: dark brown-plum feathers, a yolk-yellow beak, a green meadow behind it. Pick any swatch to read its values and contrast, then see the same colors working inside a Redaction View.

Colors by role

Colors are named by what they do, never by how they look. Select a swatch for details.

How much of each

Dark surfaces carry most of the screen. Yolk stays rare so that it always means "this is active" or "do this".

About 60%: background. App canvas and the empty space of every timeline lane.
About 30%: panels. Sidebar, editor frame, notes, menus and dialogs, one step lighter for each layer.
About 10%: accents. Yolk for actions, selection and the playhead; green for success and played audio; orange for alerts.

In context

The palette values are agreed. How roles map onto screens and states below is a proposal to react to. Lane colors are placeholders, because that palette is still to be designed.
